# 🌾 RaithuMitra AI – రైతుమిత్ర AI

### Your Smart Agricultural Companion

**RaithuMitra AI** is an AI-powered agricultural assistance platform designed to support farmers with smart farming guidance, crop recommendations, disease identification, irrigation suggestions, weather information, and agricultural knowledge.

The platform focuses on making modern agricultural technology accessible to farmers through a simple, user-friendly interface with Telugu language support.

---

## 🌱 Project Overview

Agriculture plays an important role in India's economy, but farmers often face challenges such as crop diseases, unpredictable weather, improper irrigation, pest attacks, and a lack of timely agricultural guidance.

RaithuMitra AI aims to address these challenges by bringing Artificial Intelligence into agriculture.

It acts as a digital farming companion that helps farmers access useful agricultural information and make better farming decisions.

## ✨ Key Features

- **🌿 AI Crop Disease Detection:** Helps identify crop diseases using plant images.
- **🌾 Crop Recommendations:** Provides crop-related suggestions and agricultural guidance.
- **💧 Irrigation Guidance:** Helps farmers understand irrigation requirements.
- **🌦️ Weather Information:** Provides weather-related information for farming decisions.
- **🐛 Pest Management:** Offers suggestions for managing common crop pests.
- **🌱 Fertilizer Recommendations:** Provides guidance about fertilizer usage.
- **📅 Crop Season Guidance:** Helps farmers understand suitable crop seasons.
- **💬 AI Agricultural Assistant:** Allows farmers to ask agriculture-related questions and receive AI-generated responses.
- **🗣️ Telugu Language Support:** Makes agricultural assistance easier to understand for Telugu-speaking farmers.

## ⚙️ Installation and Setup

Follow these steps to run RaithuMitra AI on your local system.

### 1. Clone the Repository

```bash
git clone https://github.com/namratha883/Raithumitra_ai.git
```

### 2. Navigate to the Project Folder

```bash
cd Raithumitra_ai
```

### 3. Install Dependencies

```bash
pip install -r requriments.txt
```

### 4. Configure Gemini API Key

Obtain a Google Gemini API key and configure it as an environment variable.

**Windows PowerShell:**

```powershell
$env:GEMINI_API_KEY="YOUR_API_KEY"
```

**Linux / macOS:**

```bash
export GEMINI_API_KEY="YOUR_API_KEY"
```

Replace `YOUR_API_KEY` with your actual API key.

Never upload your API key to GitHub.

### 5. Run the Application

```bash
streamlit run app.py
```

The application will open in your browser, usually at:

```text
http://localhost:8501
```
